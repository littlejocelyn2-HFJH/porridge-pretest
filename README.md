# 〈以粥養生〉初讀理解診斷前測

國中國文．韓良憶〈以粥養生〉初讀理解診斷工具（8 題選擇＋1 題開放書寫，約 8～10 分鐘）。
學生用手機或電腦開網頁作答，不需登入任何帳號；作答存進 Google 試算表，老師登入後可看到每位學生的**閱讀層級**、**診斷類型**與**答題特色**。

- 學生作答：`https://littlejocelyn2-hfjh.github.io/<repo>/`
- 老師成績與診斷：網址最後加上 `#scores`
- 大屏展示：老師登入後按「開啟大屏展示」（或網址加 `#screen`）

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 學生作答、成績頁、教師診斷、大屏 |
| `questions.js` | 題目、答案、錯誤選項類型、開放題關鍵詞（改題目只改這裡） |
| `config.js` | 後端網址、疑似亂答門檻 |
| `apps-script/Code.gs` | Google 試算表後端 |
| `TEACHER-GUIDE.md` | 題目、答案、診斷規準與前測結果解讀表 |

## 一、開啟 GitHub Pages

1. repo → **Settings → Pages**
2. Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾 **/(root)** → Save
3. 等 1～2 分鐘，網址會是 `https://littlejocelyn2-hfjh.github.io/<repo>/`

## 二、部署 Google 試算表後端

1. 新增一個 Google 試算表（名稱自訂，例如「以粥養生前測」）
2. **擴充功能 → Apps Script**，刪掉原本內容，貼上 `apps-script/Code.gs` 全部內容
3. 把**第 8 行**的 `change-me` 改成自己的密碼（保留引號），存檔
4. **部署 → 新增部署作業** → 齒輪選「網頁應用程式」
   - 執行身分：**我**
   - 具有存取權的使用者：**所有人**
5. 按部署、授權（若出現「Google 尚未驗證」：進階 → 前往（不安全））
6. 複製 `/exec` 結尾的網址，交給 Claude 填進 `config.js`

> 直接打開 `/exec` 網址看到 `{"ok":true,...}` 是正常的，那是後端。
> **之後如果 Code.gs 有更新**：重新貼上程式 → 再改一次第 8 行密碼 → 部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署。網址不變。

試算表會自動建立兩個工作表：
- **資料（程式用）**：每位學生一列，網頁讀這個，請不要手動改
- **作答紀錄（老師看）**：每次作答一列，可以直接篩選、排序

## 三、發布到 Google Classroom

1. Classroom → 課堂作業 → 建立 → **作業**（或「資料」）
2. 新增連結：貼上學生作答網址
3. 說明可寫：「請用手機或電腦打開連結，先填班級、座號、姓名，大約 10 分鐘。這不是考試，不計分。」

## 四、老師怎麼看結果

打開網址加 `#scores`，輸入密碼登入後有七個分頁：

1. **全班概況**：各層答對率、閱讀層級分布、開放題層次、起承轉合掌握、下一節課建議
2. **各題分析**：每題答對率、每個選項被選人數、誤選選項代表的錯誤類型
3. **學生診斷**：每位學生的層級、類型、答題特色、開放題原文；可改判開放題層次
4. **開放題分類**：依三層次分組列出全班文字
5. **作答紀錄**：最新在上，可篩座號、只看疑似亂答、複製貼到 Excel
6. **前測結果解讀表**：類型 → 對應遊戲與教學建議
7. **教師區**：匯入成績碼、大屏、清除班級資料

## 注意事項

- 分析預設用每位學生的**第一次作答**（最能反映起點），可切換成最新一次。
- 學生作答過程與交卷後都**不顯示答案、解析或分數**，以免影響診斷。學生頁只顯示「完成名單」，不排名。
- 開放題的層次是**系統依關鍵詞初判**，請老師確認；文字短不會被判低。
- 疑似亂答（用時少於 90 秒，或 8 題選同一個選項）只是提醒，請老師確認。
- 學生網路斷線時，交卷畫面會給「成績碼」，請學生私訊給老師，到教師區匯入。
- 改了 `questions.js` 或 `config.js` 之後，請把 `index.html` 裡 `?v=` 後面的數字加 1，學生端按重新整理（電腦 Ctrl+F5）。
